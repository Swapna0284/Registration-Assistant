
# AI Registration Assistant

## Overview

The AI Registration Assistant is a simple chatbot developed using Python and Flask. It helps students with registration guidance, eligibility information, and common registration queries.

## Features

- Student Registration Support
- Eligibility Guidance
- Intent Recognition
- Simple Chat Interface
- NLP-based Responses

## Technologies Used

- Python
- Flask
- NLTK
- Scikit-learn
- HTML
- CSS
- JavaScript

## Installation

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
